# Mint Choco 设计语言发散（2026-11-20）

主题：整个界面在一杯薄荷巧克力奶茶里（杯、液体分层、小料、吸管、杯套、小票、糖浆、冰块、吧台）。
约束：六条界面原则（AESTHETICS.md）；不做伪 3D、不用文具、不用菜单板点线；各页主角物件不撞。

## 第一阶段 · 18 个方向

### 类比法
1. **分层 = 时间沉积**
   核心：奶茶分层像地层，越往下越早。构图：竖向不等高色层，最新在上（奶盖），旧的沉底。交互：往下滚＝往杯底看更早；层厚＝那天的量。联系：杯里本来就分层。
2. **小料重量 = 重要程度**
   核心：珍珠沉、奶泡浮。构图：重要信息位置更低、更实，琐碎信息浮在上方更淡；视觉重心落在下三分之一。交互：长按一颗「捞起」看详情。联系：小料在杯里的真实浮沉。
3. **店里动线 = 导航**
   核心：点单 → 制作 → 出杯 → 取餐，对应 输入 → 处理 → 结果 → 存档。构图：横向吧台，页面是吧台上的不同工位。交互：前进＝沿吧台往右，返回＝往左，永远知道自己在第几站。联系：奶茶店的工作流程。

### 移植法
4. **液面晃动 → 滚动反馈**
   核心：只移植液面线的物理，不动整页。构图：内容区顶边是一条液面线。交互：滚到头时液面轻轻荡两下代替回弹；快速滚动液面倾斜。联系：杯子被晃。
5. **糖浆拉丝 → 拖动阻力**
   核心：粘稠液体有阻力和断点。构图：可拖的条目被拉出时后面拖一根糖浆丝。交互：拖过阈值丝断＝动作成立（删除仍然弹 MC.confirm）；没过阈值缩回。联系：焦糖、巧克力酱的黏。
6. **冰块融化 → 时效**
   核心：剩余时间＝冰块体积。构图：key、阅后即焚消息旁一颗冰块。交互：随时间变小变透明，化完即过期；点冰块显示剩余时间。联系：冰饮放久了会化。

### 模仿法
7. **杯身勾选格**
   核心：真实店员在杯身印好的格子里打勾（少冰、半糖、加料）。构图：设置项是一排印刷小方格+手写勾，不是开关。交互：点格子画勾动画，再点擦掉。联系：每家奶茶店杯上都有。
8. **取餐叫号屏**
   核心：叫号屏的段码数字和滚动号码条。构图：页顶一条窄叫号带，大号数字＋状态。交互：异步完成时号码翻一下并「叮」。联系：取餐等待的体验。
9. **雪克杯**
   核心：摇杯＝混合重来。构图：重新生成按钮是一只雪克杯。交互：按住时杯子左右摇（或摇手机），松开出结果；可在设置里关掉摇手机。联系：调饮动作。

### 组合法
10. **薄荷 × 植物标本馆**
   核心：每个模块像一张采集标签。构图：小字纹理用拉丁学名式的英文标注（Mentha · No.0057），细线引出说明。交互：点标签翻到背面看详情。联系：薄荷本是植物（人格页已用标本图版，可推广到说明文字体系）。
11. **奶茶 × 日式便当分隔盒**
   核心：不等分的格子装不同的菜。构图：仪表类页面按信息重要度切成大小不一的格，主格占 60%，没有等高卡片。交互：点格子原地放大，其它格挤小，不跳页。联系：外带餐盒、杯托。
12. **甜品店 × 扭蛋机**
   核心：随机惊喜用机关表达。构图：「尝一口」是一台小扭蛋机。交互：转旋钮掉出一颗糖球，打开是一段随机回忆。联系：店门口的小机台，可操作机关。

### 逆向思维法
13. **倒杯代替翻页**
   核心：进入二级页不是右滑，而是把当前杯里的东西倒进新杯。构图：两只杯子之间一道液体弧线。交互：进入＝倒（300ms），返回＝倒回；最多倒三次，正好对应最深三层。联系：倒饮料。
14. **显示「还剩」而不是「用了」**
   核心：额度、电量、key 都看杯里还剩多少。构图：杯中液位+侧边刻度，不用进度条。交互：快见底时液面颜色变莓果，杯底露出提醒字。联系：喝到见底。
15. **撒料代替列表行**
   核心：记录不是一行行，而是散落的小料。构图：一根吸管上串着小料，疏密＝频率（rv2 雏形）。交互：点一颗原地展开成一行字，其他小料让开。联系：吸管穿过珍珠。

### 系统法
16. **三种材料语法：玻璃 · 液体 · 小料**
   核心：可点的永远是实心小料，不可点的是液体，承载结构的是玻璃。构图：导航和页顶＝玻璃（毛玻璃）；内容＝液体（半透色层）；按钮/可拖物＝小料（实色+可可描边）。交互：看材质就知道能不能点。联系：一杯饮料的三种物质。
17. **出杯状态机**
   核心：所有异步统一成五态：空杯、制作中、好了、做坏了、满溢。构图：每种状态固定一种糖浆色＋一个小料符号。交互：每态配一个动效、一个音效（摇杯、叮、咕噜）、一个触感；系统设置「减少动效」时只留颜色和图标。联系：出杯结果。
18. **配方式 token**
   核心：组件＝配方（杯型 + 糖浆 + 小料）。构图：图鉴就是配方卡。交互：工程里 token 用配方命名（cup.tall、syrup.mint、topping.pearl），设计稿和代码说同一种话。联系：店里的配方本。

## 第二阶段 · 三个完整概念

### A「三种材料」（16 为骨，吸收 7、15、17）
- **页面构图**：从后到前四层。L1 条纹底；L2 玻璃（页顶、底栏、弹层，毛玻璃）；L3 液体（内容区，半透明色层，按时间或主题分层，层与层之间是一条柔和液面线）；L4 小料（所有可点、可拖的东西）。视觉重心在液体层下三分之一，小料集中在拇指区。
- **主体元素**：每页一只主角容器（已定的芭菲、糖果罐、分层杯……不换），容器里的液体层承载信息。
- **装饰层次**：装饰只放在玻璃边缘和液体内部的远景线稿，绝不放在小料周围，保证点击区干净。
- **组件形态**：一级按钮＝巧克力排块；二级＝薄荷糖珠；勾选＝杯身印刷格；列表＝吸管串小料；重要事件＝小票；有身份的条目＝杯套签条。
- **交互机制**：小料按下会「沉一下」（下移 2px 加阴影收紧），松手弹回；拖动时小料被拎起；液体不响应点击。状态统一走出杯五态。

### B「液位叙事」（14 为骨，吸收 1、6、2）
- **页面构图**：每页一只占屏 60% 的大杯，液位就是这页最重要的那个数。杯旁左侧刻度尺，右侧引线标注。
- **主体元素**：液位、分层、冰块、小料。分层＝时间，冰块＝时效，沉底小料＝重要的事。
- **装饰层次**：杯外几乎不放装饰，靠杯内的层次丰富画面；背景条纹 + 一张远景线稿。
- **组件形态**：数字直接写在液面线上；小数据用小量杯；列表折成杯底的沉淀层。
- **交互机制**：上滑＝往杯底看，杯子不动、液体层滚动；冰块随时间变小；快见底时液面变色。问题：每页都是一只杯，容易和聊天页、用量页的主角撞，页与页之间区分度低。

### C「吧台动线」（3 为骨，吸收 13、8、9）
- **页面构图**：全站是一条横向吧台，五个底栏 tab 是五个工位。页顶是叫号屏，显示你在哪一站。
- **主体元素**：工位上的器具（摇杯台、封口机、取餐柜）。
- **装饰层次**：吧台后墙是场景层，各工位后墙不同（瓷砖、窗、黑板），延续 DESIGN §1.9。
- **组件形态**：进入二级页＝倒杯过渡；重新生成＝雪克杯；完成＝叫号屏翻号。
- **交互机制**：横向切换工位有连续空间感；二级页最多倒三次。问题：横向空间和底栏切换要两套手势，工程量大；倒杯过渡每次都放会烦，需要能减少动效。

## 第三阶段 · 比较与推荐

| | A 三种材料 | B 液位叙事 | C 吧台动线 |
|---|---|---|---|
| 视觉识别度 | 中高：材质对比一眼可认 | 高：大杯醒目 | 高：空间感强 |
| 创意深度 | 高：是一套语法，能套到所有组件 | 中：一个比喻用到底 | 中高：导航叙事新 |
| 交互合理性 | 高：材质即可点性，直接解决 affordance | 中：信息全塞进杯，密度受限 | 中：横向空间与底栏冲突 |
| 工程复杂度 | 低：CSS 变量 + 组件约定 | 中：每页要画杯和液体动画 | 高：空间导航、倒杯过渡 |
| 与已定页面 | 兼容，不换主角 | 和聊天、用量页撞 | 要重排导航 |

**推荐 A 为主方案。** 它不是又一个装饰，而是一条「看材质就知道能不能点」的规则，能把已经做好的签条、小票、普通行、各页主角统一起来，不推翻已定页面。

从其他方案吸收：
- 从 B 拿 **冰块时效**（key 过期、阅后即焚）和 **数字写在液面线上**，只用在有剩余量的地方（用量页、额度）。
- 从 C 拿 **叫号屏翻号** 作为全站完成反馈，配合出餐铃；**雪克杯** 做重新生成按钮。倒杯过渡先不做，等全站动效时作为可选。

## 第四阶段 · 页面结构与技术方案

**页面结构（每页同一骨架）**
1. L1 条纹底（固定）
2. L2 远景线稿 + 场景层（固定，半透明）
3. 玻璃：页顶（返回 / 标题 / 操作）+ 底栏，固定，毛玻璃
4. 液体：内容滚动区，分层承载信息；只读内容都在这层
5. 小料：可点、可拖的控件，至少 44×44 点击区，不和装饰重叠
6. 反馈层：出餐铃 toast、MC.confirm、叫号翻号

**技术方案**
- token：`p/tok/kit.css` 用 CSS 变量按配方命名：`--syrup-mint`、`--syrup-cocoa`、`--glass-bg`、`--liquid-a`、`--topping-ink`、间距 `--s1…--s6`（4 的倍数）、字号四档、圆角同心内缩。
- 材料类：`.glass` `.liquid` `.topping`，可点元素必须是 `.topping`（自查脚本扫：有 onclick 却不是 topping 的报警）。
- 小料图标：SVG `<symbol>` 雪碧图 `p/tok/toppings.svg`，`<use href>` 引用，颜色走 `currentColor`。
- 状态：统一 `data-state="empty|making|done|fail|over"`，CSS 按状态换糖浆色和小料符号；JS 只改属性。
- 动效：只用 transform / opacity；`prefers-reduced-motion` 和站内「减少动效」开关都只留颜色变化；动效最后全站统一加。
- 字号：根变量 `--fs`，设置里可调 1 / 1.15 / 1.3，截图自查加 1.3 倍档。
- 字体：ZK / WK / BalooX / Script 按页切子集，构建时扫全文重切。
- 落地顺序：① 图鉴加「三种材料」一节灰稿 → ② 普通行、签条、小票换成 token 写法 → ③ 健康页试点 → ④ 其他页 → ⑤ 动效统一。
