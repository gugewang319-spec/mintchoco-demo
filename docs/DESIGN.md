# 薄荷巧克力手机端原型 · 设计文档

> 读者：接手修改这个原型前端的 AI 编程工具（如 Kimi Code）和人。
> 适用范围：本仓库 `mintchoco-demo`（外壳 `index.html` + `p/<页面>/index.html` + `p/pfix.js` + `bridge.js`），截至外壳版本 `V=27`。
> 写于 2026-11-14。原型里的一切数据都是**演示数据**，不连任何后端。

## 0. 先读这几条

1. 这是 PPST（Palimpsest）的手机端**交互原型**。PPST 是项目所有者茶茶自托管的私人 AI 陪伴网关：她在不同聊天入口和同一个角色聊天，网关保存对话、整理长期记忆、管理渠道和模型。原型只负责「长什么样、怎么点、怎么动」，真实功能以 PPST 后端为准（见第 3 节）。
2. 主题只有一个：**整个界面在一杯薄荷巧克力奶茶里**。新页面、新控件先回答「它在奶茶店里是什么东西」，再动手。
3. 改动前先看第 1 节的禁止项和第 5 节的动效规矩。它们来自茶茶逐版否决过的方案，不是建议。
4. 文中标「**待确认**」的地方没有定论，不要自行拍板；标「**草案**」的规矩还没被茶茶确认，可以参照，但冲突时以已确认的规矩为准。
5. 文中提到 PPST 后端时，只写模块名、接口路径、表名，不写服务器地址、域名、密钥或任何真实用户数据。往本仓库提交时也遵守这一点。

## 1. 主题与世界观

### 1.1 一杯薄荷巧克力奶茶

- 背景是薄荷竖条纹（像杯身的条纹纸杯/杯套），顶部是一道巧克力淋酱（`today-bg.png`），淋酱随内容一起滚走。
- 每一页是杯里或吧台上的一样东西：今天页是一杯芭菲，记忆页是糖罐和包装台，聊天列表是奶盖、冰块和沉底的珍珠，聊天室在奶茶杯里，人格页是一杯分层饮品配小票，设置页是印在杯身上的「营养成分表」，子页分别是挂单轨（渠道）、菜单（模型）、黑胶（声音）、手环数据（健康）、量筒（用量）、糖粉筛（搜索）。
- 小料（巧克力碎、薄荷叶、糖、珍珠）只是点缀，**装饰跟着结构走**：压在行尾、挂在角上、沉在杯底，不能为了好看随手撒。
- 一律**正面平视**。不俯视，不做斜着的立体块。唯一例外：聊天列表「本周」的冰块日历是招牌，允许保留立体块（2026-11-12 茶茶同意）。

### 1.2 配色（631）

| 占比 | 内容 | 原型里的值 |
| --- | --- | --- |
| 60% | 薄荷奶底 | 背景 `#e4f3ec` 及竖条纹；薄荷 `--mint #c4e8da`（偏青，不要偏黄） |
| 30% | 奶油、奶茶（含毛玻璃） | 奶油玻璃 `rgba(252,250,244,.62)`；奶油纸、奶层 |
| 10% | 巧克力 | 深巧克力 `--ch #5b3a2c`、墨色 `--ink #4a3027`、可可 `--cocoa #8a5c46` |

- 强调色：深薄荷 `--mint3 #2f6e58`（部分页为 `#3f9a80`）、`--mintb #3f9a80`；少量粉 `--pink #e07f95`（仅个别页）。
- 巧克力已经被淋酱、标题、数字、珍珠占用，**按钮不要再用深色实心**（控件草案第 4 节）。
- 生图素材里的薄荷要调成偏青（蓝通道往绿通道靠约 55%），否则和底色打架。

### 1.3 描边

- 代码画的物件统一用**可可色细描边**（`--ol / --cocoa #8a5c46`，约 1–1.5px）。
- 生图物件用「统一粗细的暖可可色细描边」（写在生图提示词里）。
- 奶盖、奶层的描边**不闭合**（留口），见禁止项「闭合奶盖圈」。

### 1.4 字体

| 字体族（CSS 名） | 文件 | 用途 |
| --- | --- | --- |
| `ZK`（站酷快乐体，子集） | `zk.ttf` | 中文标题、页签、计数、主操作字 |
| `WK`（霞鹜文楷，子集） | `wk.ttf` / `wenkai.ttf` | 中文阅读正文（摘录、明细、长段） |
| `Baloo`、`BalooX`（800 字重静态版） | `baloo.ttf`、`baloo800.ttf` | 大数字（128.4、6,284、1,284） |
| `Script` | `script.ttf` | 标题后面的英文手写字（memory、chats、settings…）；具体字体名**待确认** |
| 系统无衬线 / Noto Sans SC | 系统 | 底栏字、小字 |

- 中文字体都是**按页切的子集**。新加中文字前先确认子集里有，没有就重切（历史上「配料」「工具」「搜索」掉回系统字体就是因为缺字）。Baloo 栈后面要接 `ZK` 兜底，否则中文落到系统字体。
- 页标题：`ZK` 32px，深巧克力色，后面叠一行英文 `Script`。

### 1.5 画风

- **复杂物件生图**：芭菲、糖罐、糖纸、冰块、珍珠、小票、黑胶、糖粉筛、薄荷枝、杯子等用 AI 生图，画法是**彩铅加水彩（水粉）**，柔和低饱和，左上来光，带纸纹。
- **简单形状用代码画**：线、波浪、奶层、淋酱、刻度、勾、圈、量筒，用 CSS/SVG/Canvas。代码画法试过模仿彩铅（`feTurbulence` 抖边、噪声颗粒），冰块三版都被否，**复杂物件不要再用 SVG 硬画**。
- 生图模板（实际生成用英文版，摘自 PPST `docs/design/生图提示词.md`）：

```
[SUBJECT], flat front view, single object centered.
STYLE: soft hand-drawn gouache and colored pencil illustration, thin warm cocoa outline of consistent weight, light from top-left, subtle paper grain texture, muted palette of cream white, low-saturation mint, milk-chocolate brown and dark cocoa, vintage 2000s Japanese stationery scrapbook.
For stickers add: even thick white die-cut border.
Isolated on solid pure chroma green #00FF00 background.
No text, no letters, no watermark, no cast shadow, no photorealism, no 3D render, no flat vector.
```

- 抠图：按「绿比红、蓝高多少」算透明度；去绿溢色只在半透明边缘做，不碰实心区（否则薄荷会被洗灰）。薄荷色素材阈值放宽到 45–125。
- 不加投影，不加高光反光带。

### 1.6 少文案

- 不加次要标签、操作说明、slogan（「点一下……」「越新越靠上」这类都删过）。
- 补充信息收进 **ⓘ**，点开就地展开。
- **必须保留**：表单标签、读屏名称（`aria-label`）、删除 / 支付 / 永久变更的**后果提示**。
- 空状态写一句话加一个下一步链接；数据过期整块变灰加一句说明（新功能接入规范第 6 条）。

### 1.7 交互总原则

- **不挡背景**：不用大面积纸张、卡片、容器把条纹背景盖没。
- **少弹窗**：普通点击在物件本身上就地反应（晃、跳、展开、打印出来）。例外（2026-11-19 茶茶改）：危险操作弹警告窗；做完一件事给「出餐铃」。
- 展开物（小票等）收起：**点挂着的吸管，或往下拉**，不用 × 钮。
- 多选一的字段：**点开就地展开小选单**，不用「点一下换一个」的循环钮。
- 删除、永久变更：弹警告窗（`p/ui.js` 的 `MC.confirm`）：毛玻璃小卡、三角警示、标题一句问句、正文写后果（要紧处红彩铅底），一级巧克力牌写动作（「删掉」），下面四级文字「再想想」；点遮罩等于再想想。
- 做完一件事（挂上去、改好、删掉）：页顶滑下毛玻璃「出餐铃」（`MC.toast(文字,{undo})`），铃铛晃一下，一句话 + 可选「撤销」，约 3 秒自己收。页面用到它要把 ui.js 里的字切进本页字体。
- 没填全就晃一下，必填项变红线。

### 1.8 禁止项清单

以下都是茶茶否过的，不要再带回来：

- 胶囊标签、胶囊按钮、胶囊筛选
- 开关（toggle switch）
- 筛选控件（chip 筛选、筛选行）。**例外待定**：聊天列表页头的筛选圆钮
- 伪 3D、高光卡片、3D 按钮
- 斜向反光带
- 拱形
- 花环、藤蔓、小花
- 等高卡片网格（「一排出风口」「空调出风口」）
- 闭合的奶盖圈
- 蝴蝶结、丝带
- 「一件东西配一段字，左右交错」的版式
- 「杯子居中，两侧引线标注」：**只给人格页用**，别的页不用
- 弹窗、底部抽屉、遮罩
- 冰封、半透明冰块效果（聊天列表）
- 底部长条按钮、线圈装饰、贴图感拼贴
- 全屏纸纹、暖色描边、统一阴影的「溶图滤镜」
- 吸管戳膜转场（太碍眼，已换成「续一口奶茶」）

## 2. 页面地图与交互

### 2.1 地图

```
底栏五格（固定，不加）：今天 · 记忆 · 聊天 · 人格 · 设置

今天 ──点「最近聊天」──▶ 聊天室
     └─点「记忆候选」──▶ 记忆（切 tab）
聊天 ──点今天的奶盖──▶ 聊天室
     └─搜索圆钮────▶ 搜索
设置 ──点大数字 128.4──▶ 用量
     ├─展开「渠道」行，点「去调 ›」──▶ 渠道
     ├─展开「模型」行，点「去调 ›」──▶ 模型
     ├─展开「声音」行，点「去调 ›」──▶ 声音
     └─展开「健康」行，点「去看 ›」──▶ 健康
子页左上毛玻璃圆钮 ──▶ 返回上一页
```

跳转写在各页底部的 `window.__DEMO_MAP`（选择器、动作、是否保留页内反应、延迟毫秒），由 `bridge.js` 转成 `postMessage` 交给外壳。

### 2.2 转场

| 场景 | 做法 | 时长 |
| --- | --- | --- |
| 切底栏 tab | 新页淡入（opacity 0→1） | 200ms |
| 进子页（push） | 「续一口奶茶」：新页随一道晃动的液面从底部涨上来；液面是白奶沫线 + 薄荷描边 + 下方半透明薄荷奶带 + 几颗小泡，阻尼正弦波加起始倾斜，ease-out（三次） | **430ms（待确认的例外）** |
| 返回（back） | 液面落下，子页像被喝掉，上一页一直垫在下面 | **380ms（待确认的例外）** |
| 减少动效 | 直接切换，无动画 | 0 |

实现要点见第 6.3 节。

### 2.3 各页

每页写四件事：主角物件、能点什么、点了就地怎么反应、转场。

#### 今天 `p/today`

- **主角**：一杯薄荷巧克力芭菲（生图 `parfait.png`），斜穿一条 S 形缎带当构图线；顶上大日期「11.11 周三」。
- **能点什么**：
  - 芭菲上插的三支签：今日提醒（数字）、新消息（数字）、漫想（♡）。
  - 左侧四张饮品卡：他现在（热可可）、最近聊天（珍珠奶茶）、他的日记（拿铁）、记忆候选（薄荷苏打）。
- **就地反应**：签被点后按各自的角度弹簧甩一下；饮品卡里的液体用一维浅水方程模拟（`lq.js`，移植自 slosh），点哪一侧哪一侧被按下去、撞壁回弹两三下才停；棉花糖跟着液面浮，珍珠跟着流速漂；待机时每杯按自己的周期轻晃，手机倾斜也会流（需 HTTPS）。淋酱尖端偶尔滴巧克力，Canvas 飘少量糖粒。
- **转场**：点「最近聊天」380ms 后进聊天室（push）；点「记忆候选」380ms 后切到记忆 tab。
- 注意：页里还留着一段底部弹层（`.sheet` / `openK`）的旧代码，已不被调用（2026-11-11 去弹窗）。**不要重新接上**，可以删（待确认后删）。

#### 记忆 `p/mem`

- **主角**：一只糖罐（`jar.png`）站在包装台上；页头大数「128 颗记忆」，下面小字「经历 46 · 认识 82」。
- **能点什么**：
  - 包装台上的候选糖纸（`wrapper.png`，正面写类型 · 主体和正文），下面两个钮：**包好**（✓）、**化掉**（×）。
  - 罐子本身。
  - 「最近收进罐子的」索引：左栏日期 + 类型，右栏标题和正文，长条目可展开（`aria-expanded`）。
  - 页头右上「搜索记忆」毛玻璃圆钮（**未接任何动作**，待确认是否做记忆搜索）。
- **就地反应**：包好 → 当前候选飞进罐子，罐盖微开再合；化掉 → 糖纸化开淡出，下一张补上；点罐子罐子晃；点索引里的糖会弹一下；长条目原地展开全文。待复核的条目用圆点标记，主体看糖纸颜色。
- 去掉过的东西：「全部 / 经历 / 认识…」筛选行和筛选圆钮（2026-11-12），slogan 和说明句（2026-11-13）。
- **转场**：底栏 tab，淡入。

#### 聊天列表 `p/list`

- **主角**：一杯奶茶的剖面：最上面一层奶盖 = 今天；中间一摞冰块 = 本周（每块一天，日期在顶面、星期竖排在侧面、最后一句在正面）；杯底珍珠 = 更早的几周（每颗一周，日期范围 + 天数 + 一句）。奶盖顶上有动态滴落的巧克力酱。
- **能点什么**：奶盖（今天）、每块冰块、每颗珍珠、「今天聊了 6 轮 ›」虚线链接、页头的搜索圆钮和筛选圆钮。
- **就地反应**：点奶盖，奶盖上的酱晃一下，300ms 后进聊天室；冰块、珍珠被点时往下一沉再浮回（只动图片层，字不动）；酱汁是黏稠滤镜（模糊 + 阈值），每次只有两条在动：慢垂、尖端一掐、缩回。
- **转场**：点奶盖 push 聊天室；搜索圆钮 push 搜索页。筛选圆钮目前无动作（**待定**：要不要保留）。
- 冰块、珍珠是生图版（`ice.png`、`pearl.png`、`pearls.png`）；三版 SVG 重画（list3–list5）都被否，不要再改回代码画。

#### 聊天室 `p/room`

- **主角**：整段对话在一杯奶茶里，杯子固定在右下，内容从它前面滚过；页头标题是日期「11 月 11 日 周三」，下面一行「● Telegram ｜ 前 12 轮已总结 ›」。
- **元件**：时间分隔是巧克力小方块计数器（08:12）；他的气泡是淋了巧克力酱的奶冻，我的气泡是薄荷果冻（里面冒泡）；每轮下面一行「入口 · 时间」和「模型名 · 第 N 轮」；「另 2 版」是虚线链接；「N 条候选」是薄荷小字；「他存了一条记忆」是一颗包好的糖；结尾「这一天喝到杯底啦」。
- **能点什么**：气泡、糖、杯子、「前 12 轮已总结 ›」、左上返回、右上「更多：删除这一天的记录」。
- **就地反应**：点气泡，气泡上的巧克力酱/小料甩一下，我的气泡冒一串泡；点糖，糖晃一下；点杯子，杯里液面晃、冒泡；巧克力酱每个气泡只有 1–2 条在动（慢垂、尖端一掐、缩回，周期 9–16 秒，不滴到字上）。「更多」目前无后续（删除入口未定）。
- **转场**：从今天页或聊天列表 push 进来；返回钮 back。

#### 人格 `p/role`

- **主角**：一杯分层饮品（`cup3.png`，尖顶奶油），**杯子居中、两侧引线标注**（本页专用）：每层对应人格的一段（性格 / 和茶茶 / 说话方式 / 小习惯），引线按实际字宽画；杯边贴入口名（Telegram、API、QQ）。标题「叶铎的配方」，下方版本计数器「第 12 版」和字数。
- **分段规则（原型）**：先看她写的小标题（`# 标题` 或 `【标题】`），没有就按空行分段，都没有就是一整杯；最多 4 层标在杯子上，第 5 段起只进正文。正文版式按内容定：首段首字下沉；有分号或换行的排成清单；很短的做引语；其余用边注；相邻两段不重复同一种版式。
- **能点什么**：杯上的吸管 / 引线标注、正文任一段、撤销、重做、保存三颗钮。
- **就地反应**：
  - 点标注：拔出一根吸管，吸管短头穿过热敏小票（`receipt3.png`）的孔把小票挂出来，小票上是该段明细（选中 `[✓]`、未选 `[ ]`）；物件磁吸贴在小票左上角背后露半截，回弹后「咚」一下。**收起**：点挂着的吸管，或把小票往下拉。
  - 点正文：那一段原地变成可编辑（`contentEditable`），停手约 0.45 秒记一步历史。
  - 撤销 / 重做：描边圆；保存：有改动时为实心可可圆，不可用时为虚线空心圆（不是灰块）。保存后版本计数器翻一下。
  - 电脑上鼠标靠近哪根吸管，哪根微微上提。
- **转场**：底栏 tab。
- 注意：小票展开时有一层 `.veil`（浅薄荷 + `blur(3px)`）。是否违反「不挡背景」**待确认**。

#### 连接 `p/conn`（开场送信）

- **主角**：一只文鸟（薄荷背、可可帽，生图两帧 `bird_u/bird_d.webp`）叼来的信封（`env_c` 封好、`env_o` 打开、`env_f` 前袋），拆开后是一封 CSS 奶油信纸（双线薄荷边、两道折痕）。页名「请柬 invitation」。

## 4. UI 组件规范

### 4.1 页头 `.lhead`

| | 主页（记忆、聊天、人格、设置） | 子页（渠道、模型、声音、健康、用量、搜索） |
| --- | --- | --- |

| 标题底边 | 距页顶 **102px** | 同左 |

### 4.2 毛玻璃圆钮 `.pearlbtn`

- 44×44 圆，`background: rgba(252,250,244,.62)`，`backdrop-filter: blur(18px) saturate(120%)`，1px `rgba(255,255,255,.85)` 亮边，上沿内高光，`0 8px 18px -12px rgba(74,48,39,.45)` 阴影。图标可可色描边。

### 4.3 底栏 `.pnav`

- 五格固定：今天、记忆、聊天、人格、设置。**不加格**。

- 子页也显示底栏（设置高亮），底栏不随内容滚。
- 内容底部要留出底栏高度的滚动空间，珍珠等装饰沉到底栏后面，不压字。

### 4.4 链接

- 写成**可可色虚线下划线 + ›**：如「今天聊了 6 轮 ›」「前 12 轮已总结 ›」「去调 ›」「拉新的 ›」「+ 接一条新渠道 ›」。

### 4.5 小标签

- 写成**圆点 + 小字**：如「● 今天」「● Telegram」「● 默认」。
- 不用胶囊，不用底色块。
- 状态小字（配料段「未连」「3 个」）写在名字右上角。

### 4.6 新功能入口（已确认的接入规范）

1. 底栏五格不加；设置页成分表只放渠道、模型、声音、健康四行，不加。新功能一律写进「配料」段：名字后跟小字状态，自动换行。
2. 子页骨架：`.lhead` 页头（左毛玻璃返回钮，中文标题加英文手写，右 counter），进出用「续一口奶茶」转场。
3. 一页一个主角：先在奶茶店里找对应物件，生图，彩铅加水彩，正面平视；数据写在主角身上，或沿一条对齐线印出。
4. 结构以真实代码为准：一个面板对应一段；列表写成对齐的行加点线；表单就地展开，保留标签；要过滤就点上面那一块。

8. 动效：能点的待机要动，周期各自独立；不能点的静止；支持减少动效。
9. 交付前：对照代码核功能，切字体子集，截图核溢出，接进演示外壳。

- 所有 `button, .tab, .lt, .dk, [role=button]`：按下 160ms 缩到 `scale .97`，松开 140ms 回弹，曲线 `cubic-bezier(.23,1,.32,1)`（松开比按下快）。

## 5. 动效规范

### 5.1 基本规矩（来自 emil-design-eng 的做法，已在 v21 落实）

- 按下缩到 `.97`；松开回弹，**松开比按下快**（160ms / 140ms）。
- **不用 `ease-in`**。界面动画用强 ease-out：`cubic-bezier(.23,1,.32,1)`。
- **不从 `scale(0)` 开始**。出现动画从 `.9` 左右加透明度开始。
- 界面动画**不超过 300ms**。例外：进子页 430ms、返回 380ms 的液面转场，**是否保留为例外待确认**。另外返回用的是 smoothstep（缓入缓出），和「不用 ease-in」是否冲突也**待确认**。
- 待机动画（晃、漂、滴）不受 300ms 限制，但每件物件周期要各自独立（如 5.3s / 6.9s、9–16s），不要同步，不要用同一条正弦波让所有东西一起伸缩（「像橡皮筋」被否过）。

### 5.2 减少动效

- 每页都要读 `prefers-reduced-motion: reduce`：CSS 全局关动画，JS 帧循环加守卫，不播初始泡泡、灌注、打印动画，转场直接切换。
- 拖拽甩动、弹簧等也关。
- 新页面上线前用减少动效模式各走一遍。

### 5.3 什么要动、什么不动

- **可点的东西待机要动**（轻晃、浮动、慢转、偶尔滴落），让人知道能点。
- **不可点的东西静止**（散放的小插画、背景、纯装饰）。
- 点了在物件本身上反应：晃、跳、沉、冒泡、甩、展开、打印出来。

### 5.4 性能规矩

- **帧循环里不读布局**：不在 `requestAnimationFrame` 里调 `getBoundingClientRect`、`offsetWidth` 等。尺寸在初始化和 `resize` / `ResizeObserver` 时缓存。
- 只更新屏幕里看得见的物件。
- **会动的背景上不盖大面积 `backdrop-filter`**：大面积毛玻璃压在动画上每帧都要重算模糊。底栏、圆钮、量筒这类小块可以用；整屏遮罩、大卡片不要用。
- **每帧由 JS 写 `transform` 的元素，不要再给它加 CSS `transform` 过渡**：过渡会被反复重启、越叠越大（记忆页糖纸被甩出可视区就是这个原因）。只过渡 `opacity`，需要过渡 `transform` 时临时加类、动画完再撤。
- 外壳转场全走合成层：外框平移、iframe 反向平移，内容不重绘；`will-change` 只在动的时候加。
- 页面有性能分级（`lowtier` 类）：低端设备减少粒子和滤镜。
- 测转场流畅度：用 Playwright + CDP 压慢 CPU，逐帧记录 rAF 间隔和 long-animation-frame，分开「等加载」和「动画本身」的掉帧。

## 6. 工程约定

### 6.1 目录

```
index.html          外壳：iframe 页面池、底栏切页、子页转场、防缓存版本号 V
bridge.js           注入每页：把页内点击按 window.__DEMO_MAP 转成 postMessage 给外壳；底栏 .pnav .tab 切 tab
p/pfix.js           注入每页：页头随滚动、顶部渐进模糊、淋酱位置、底栏高亮、按压反馈、锁横向滚动
p/<页面>/index.html 一页一个自包含 HTML（CSS、JS 内联），素材和字体子集放同目录
docs/DESIGN.md      本文
```

页面目录名：`today` 今天、`mem` 记忆、`list` 聊天列表、`room` 聊天室、`role` 人格、`set` 设置、`chn` 渠道、`mdl` 模型、`snd` 声音、`hlt` 健康、`use` 用量、`srch` 搜索。

- 打开 `index.html#页面名` 从那一页开始（默认 `#today`）；单独打开 `p/<页面>/index.html` 也能看（没有外壳时 `bridge.js` 不生效）。
- 每页底部顺序：`<script>window.__DEMO_MAP=[...]</script>`、`../../bridge.js`、`../pfix.js?v=N`。
- `__DEMO_MAP` 每项：`[选择器, 动作, 是否保留页内反应(1/0), 延迟毫秒]`；动作是 `tab:页`、`push:页`、`back`。

### 6.2 防缓存版本号

- 外壳 `index.html` 里 `const V=27`，用于 `p/<页>/index.html?v=V`。
- 每页引用 `../pfix.js?v=27`。
- **每次发版两处同步加 1**：外壳的 `V` 和所有页面里的 `pfix.js?v=`。只改一处，手机上会读到旧文件。
- `bridge.js` 目前没有版本号，改它时要注意缓存（**待确认**是否也加）。

### 6.3 外壳要点

- 页面池最多常驻 10 页，超出卸掉最久没看、且不在返回栈里的页。
- 子页预载：进入某主页后空闲时预载它的子页（今天→聊天室；聊天列表→聊天室、搜索；设置→渠道、模型、声音、健康、用量）。首屏画完后预载另外四个主页。
- 开动画前等新页 `fonts.ready` 并画完两帧，避免中途卡一下。
- 隐藏页用 `visibility:hidden`（`.pg.off`），不要用 `display:none`（会让页内量尺寸的引线、酱汁算错）。
- 转场期间盖一层透明 `#shield` 防误触。

### 6.4 必守

- **`.app` 不能带 `transform`**（也不要加 `filter`、`perspective` 等会生成包含块的属性）。页面和 `pfix.js` 依赖 `position:fixed`（底栏、淋酱、顶部模糊条），祖先一旦有 transform，fixed 会变成跟着内容走。（原因是推断，规矩本身已定。）
- 滚动层锁横向：`overflow-x` hidden/clip，并在 scroll 时把 `scrollLeft` 归零。
- 加中文字后重切该页字体子集；Baloo 字体栈后接 `ZK`。
- 演示数据里不放真实密钥、域名、地址、聊天内容；网址一律用 `example` 域名或 `<你的域名>` 占位。

### 6.5 测试视口

- 必测：**358×622**（矮屏）和 **412×715**。
- 历史上还测过 360 / 393 / 412 / 430 宽、字号放大 1.3 / 1.5 倍、横屏；已知遗留：声音页 360 宽时装饰字「晚风」出屏。
- 检查：横向溢出、截字、元素压字（珍珠、小料不能压正文）、减少动效、来回切页后内存与 DOM 节点不涨。
- 截图工具：Playwright（Chromium headless）。字号放大要把每个元素的计算字号乘系数，不要用整页 zoom。
