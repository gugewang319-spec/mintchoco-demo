# 字号与操作规范（草案 2026-11-18，待茶茶确认后并入 DESIGN.md §1.4 / §4）

## 1. 文字四级 + 数字三级
| 级 | 用途 | 字体 | 字号/行高 | 颜色 |
|---|---|---|---|---|
| L1 | 页标题 | ZK | 32 / 1.0 | 深巧 #5b3a2c |
| L2 | 段名、主角名 | ZK（英文 Baloo 600） | 20 / 1.2 | 深巧 |
| L3 | 正文、行名、型号 | WK 15 / 1.5；英文 Baloo 600 15 | | 深巧 |
| L4 | 注释、单位、状态 | WK 12 / 1.4；英文 Baloo 600 12 | | 可可 #8a5c46 |
| 数大 | 主角数字 | BalooX 28 | | 深巧 |
| 数中 | 行内数值 | BalooX 18 | | 深巧 |
| 数小 | 小计数 | Baloo 700 13 | | 深巧 |
- 单位比数字小一档（0.6×）。字色只用四种：深巧、可可、薄荷深 #2f6e58（选中/生效）、警示 #8a3f28。
- 底栏小字维持系统无衬线 11。一页最多同时出现 L1–L4 + 一种数字级别。

## 2. 操作四级
1. **直接点主角**：选中、展开、切换都点物件本身。反馈在物件上（挤压 .32s），选中 = 薄荷光晕 + 名字变薄荷深。拖动 = 换序。
2. **主按钮**：每页最多一个，是画出来的场景物件（例：冰淇淋勺 = 上新）。48–56px，待机微动，按下挤压，完成有一个结果动画。字 L4 写在物件上或下方。
3. **次按钮**：圆钮。页头用毛玻璃 44；面板内用描边圆 36 + 可可图标（下方 L4 小字）。不可用 = 虚线空心圆。
4. **文字链接**：只用于「去另一页」，虚线 + ›。切换、保存、展开不再用文字链接。
- 多选一：点物件或就地小选单（§4.8）。是/否：手绘勾选框，勾是一笔画出来的动画。
- 危险操作：就地写后果，再给警示色描边圆「确定」。

## 3. 普通区域（列表、表单、设置行）的打磨
- 不做等高流水：行高跟内容走；组名 L2，组内第一行可加重；行间用点线引导线，不用卡片格。
- 间距只用 4 / 8 / 12 / 20 / 32 五档，组间 32、行间 12，形成节奏。
- 每行都有按压态：薄荷淡底 160ms 出现、140ms 退；› 右移 2px。
- 数值变化滚动翻牌；新增行高度展开 + 淡入；删除行先变灰再收起。
- 输入框：点线下划线，聚焦时变实线薄荷深；标签缩成 L4 停在上方；出错晃一下、线变警示色。
- 空状态一句 L3 + 一个链接；加载用淡铅笔线骨架。
- 平的东西要有一点体积：厚度边或上沿高光、贴地阴影（multiply），和插画同光源左上。
- 触控最小 44×44；有键盘焦点环（薄荷虚线圈）；数字等宽。

## 4. 否决清单的读法
历史否决针对当时那一版的具体做法，不是永久禁用。按钮、卡片、胶囊等可以回来，条件是：有体积、有交互细节、和这一页的主角同画风。
