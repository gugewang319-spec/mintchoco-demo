# 审美笔记（茶茶给的参考 → 学到的方法）

只记方法，不搬元素。每次精修组件前先读一遍。

## 2026-11-20 票根/小票七张（CoC 票根、@ssugartype 聊天框、石原包美《漏网之鱼》票根、ILUwm Frosted Clarity 镭射票、风 Elysium 镭射票练习、月希星星票根模板、红烧兔头 Aurora 票根素材）
1. **一个压得住的大标题**：花体 / 衬线斜体 / 粗字标，占画面 1/3，可以压过图框边（字叠图是杂志手法）。小字全部当纹理。
2. **三色以内，高对比**：蓝白黑、红米黑、藏青米白。同一张票出 2–3 个换色版（浅底 / 色底 / 深底）表示不同状态。
3. **画面窗**：拱门、椭圆、波浪圆、长方形——票是相框，里面放主角图。
4. **细线装饰而不是粗描边**：双细线内框、虚点线、角花、绕星的椭圆轨道、点线上缀小星。外轮廓通常不描边，只靠底色和投影。
5. **票根区**：竖排小字、大号竖排编号、圆形环绕文字章、条码/二维码感的小块；打孔半圆 + 虚线分隔。
6. **边缘有工艺**：邮票齿边、打孔、剪角。
7. **渐变是色场往白里化开**（Elysium），不是 3D 光泽。
8. **拼贴密度**（Aurora）：格纹块、圆形徽章、色票圆点列、诗句微缩字，层层压角但中间留白。
9. **对齐与留白**：元素都卡在网格上，边距充足；乱中有序。

## 字体选择（茶茶 2026-11-20 给的选字方法）
- 先定字形（黑/宋/手写），再定笔画（圆润=亲和包容，尖锐=硬朗科技），再定字重（细=精致，常规=正文，粗=标题）。
- 薄荷巧克力店是甜品店：标题走圆润型粗字 → ZK；正文常规 → WK；数字 BalooX；英文手写 Script。不许落到系统字（茶茶手机系统字是手写体）。

## 六条界面原则（茶茶 2026-11-20 给，每次精修自查）
1. 世界观一致：材料、字体、图形、图标、动画同一套语言（我们是「杯里的世界」：小料、吸管、杯套、小票）。菜单板式点线引线不属于这里（rv1 被否）。
2. 可理解：一眼看出能点/拖/翻；造型可以新，操作要好懂。
3. 状态反馈：点击、选中、加载、成功、失败都有明确反应；动画不能挡操作。
4. 功能与装饰分层：内容、控件、装饰、动效分开设计；装饰不挡信息和点击区（vb7 薄荷圆挡字被指出）。
5. 导航一致可预测：返回、确认、关闭行为稳定，知道自己在哪、能否退回。
6. 可读与适配：字清楚、按钮好按、适配屏幕；必要时支持调字号、减少动效。

## 「舒适」的构图和物件（参考 @kkiracore 直播包 for @chiffonbunni，2026-11-20 茶茶：「我们的构图还有物件就要这样舒适」）
只学方法，蝴蝶结、兔子、草莓、格子底都不搬。
1. **一个色相走到底**：全画面一个色系分浅/中/深三档，只多一个深可可做重点；描边用同色系深色，不用黑/纯可可。→ 我们：薄荷三档 + 可可一点。
2. **内容窗安静，装饰住在边上**：中间大块留白给内容，物件挤在边框、角落和上下沿，密度从边缘往中心递减。
3. **物件坐在框上**：每件小物都压在框边或出框一半，有落脚处，不在空中乱飘。
4. **统一画风参数**：所有物件同一描边粗细、同一种平涂 + 一道浅色亮面、尺寸只有两档（小物/中物），所以多也不乱。
5. **边缘做成一条连续的「装饰带」**：顶部一排遮阳棚波浪、底部一排马卡龙，重复同一形状形成节奏。→ 我们：杯口奶盖波浪、杯底一排珍珠。
6. **重复的行 + 间隔装饰行**：内容行和装饰行交替，长列表也有呼吸。
7. **小图标当纹理**：×、?、↗、气泡这些小 UI 符号同尺寸撒在空处，既是装饰也像界面。
8. **薄厚度**：外框下方再错开一层同色深边 + 内侧虚线缝线，有一点点厚度但不是 3D。
9. **一处打破**：整齐网格里只有一张卡微微倾斜（schedule），视觉焦点就出来了。
10. **底纹极低对比**：同色系浅格子/剪影，只有凑近才看见。

## @kkiracore 作品集续（聊天挂件 / 面板 / 窗口叠层 / 周程，2026-11-20）
只学方法，狐狸、蝴蝶结、蝙蝠翅膀、骨头、四角星都不搬。
1. **同一家族分两档**：普通消息条＝简单长条；事件条（关注、打赏）＝同一长条 + 吉祥物从一侧出框 + 整条渐变 + 花体一句。档位靠「多了什么」区分，不换形状。→ 普通行 / 签条 / 小票同理。
2. **每条固定三个锚点**：左缘骑一颗小图标（一半在框外）、上缘左侧挂名字小标签、对角放一个小点缀。位置固定，所以几十条也整齐。
3. **上缘挂一道垂幔 + 单侧吊坠**：只挂在一条的上沿和一侧，不满铺，长条就有「上方」的重量感。→ 我们可用奶盖沿 / 吸管。
4. **面板＝物件剪影**：捐赠是包、规则是夹板、社交是创可贴；标题是手写大字压在物件上。→ 器皿＝组件。
5. **卡片上下沿做花边带**：顶一条细花边、底一条波浪，中间留白放字；号码徽章骑在右下角。
6. **浮出的标签群**：几颗小标签用虚线串起来漂在主体旁边，表示一组相关信息。
7. **窗口系统**（紫色那张）：用「操作系统窗口」当统一语法，大量小窗都是同一套标题栏，所以元素再多也是一种语言。→ 我们的统一语法是「杯里的物质」（IDEATION A）。

## @kkiracore 作品集续 2（bochii 粉 / axiom 荧绿 / leecchie 橙棕，2026-11-20）
1. **换皮不换骨**：三个客户几乎同一套版式（长条+日期徽章+时间签），只换色板和一个母题（创可贴 / HUD 切角 / 猫耳），整套就成了不同世界。→ 我们的骨架全站统一，各页只换「一个母题」。
2. **事件档用反色**（leecchie）：普通消息奶黄底深字，重要事件直接深可可底浅字，不靠加东西。→ 普通行事件档可以试「深可可液体 + 奶白字」。
3. **顶沿一个剪影破形**：卡片上沿冒出两只猫耳，整张卡立刻有角色。只破一处。
4. **侧边短把手**：卡片左右各两道短横「=」出框，像能拎起来的器物。
5. **从一角渐隐的像素格**（bochii）：装饰从角落向内由密到疏，自然收住。（我们 vb3 的巧克力排块格渐隐同理。）
6. **HUD 法**（axiom）：切角、刻度短线、条码、角标，用细线就把科技感做满，同色一套。
7. **日期写在徽章上**：左侧心形/圆章写日期，右侧小签写时间，信息即装饰。

## 强调文字 12 技巧（一闪设计，茶茶 2026-11-20）
放大、加粗、变色、划线、用框包围、加上点、2 条线、3 条线、加上形状、加上线框、1 字 1 框、加点装饰。→ 事件/重点靠文字本身强调，不加底色块（rv8 薄荷色块被否）。我们的对应：ZK 放大、关键数字薄荷 BalooX、三条短线、珍珠着重点、花体小句。

## 文字三档 · 表现性排版（2026-11-20 茶茶给）
- 时间线文字分三档，制造节奏、不抢注意力：普通记录保持轻；有特殊数据的只把数字局部放大（可可色 BalooX）；真正重要的事件/成就/当前选中才用表现性排版（引导小字 + 薄荷大数字 + 单位错位 + 花体）。
- 不是每条都放大数字，否则列表又失去主次。
- Expressive Typography：文字可沿曲线排（花体沿液面波线）、嵌进纸张缺口、随物件结构转向、与装饰遮挡。
- **文字本身就可以是装饰，不必每次都往文字旁边再加一颗星星。**

- 文案不用店里黑话（开单/出杯/作废），状态用大白话；装饰小字也要写有用的信息，不放空洞英文。（2026-11-20）

## 少文案（2026-11-20 23:23 茶茶定，全站）
- 不加多余次要标签、说明、辅助文案、slogan、教学段落、每块下的帮助说明、冗余微文案；让布局、层级、间距、清晰主操作自己解释。
- 确需补充：info 图标 + tooltip，不常驻小字。
- 保留必要表单标签与可访问名称（aria-label / role）。
- 危险或不可逆操作（删除、支付、永久变更）必须留清楚后果提示。
- 去掉说明后，第一次用的人仍知道下一步点哪、点了会怎样。
- 重写旧界面：先删冗余标签和说明；清晰度降了再改布局和按钮文案。
- 删掉文字后的空，用图形装饰和图片处理（双色调、网点、色块圆）补，不用废话补。（2026-11-20）

## 三种尺度（2026-11-21 茶茶，kkiracore 直播包与聊天框参考）
- **大尺度 · 装饰结构**：决定页面轮廓、背景、大面积图案、主视觉焦点。如花边框架、巨大心形、角色立绘、特殊形状的内容容器。
- **中尺度 · 组件装饰**：按钮、卡片、日期徽章、标签、边缘挂件。让重复组件有个性，但不改阅读秩序。
- **小尺度 · 纹理与微装饰**：小星星、细点阵、织物纹、短虚线、局部高光。填节奏，不当焦点。
- 我们的毛病：只有中尺度矩形组件 + 少量小尺度符号，缺真正建立画面的大尺度结构；组件画得再精致也救不了页面偏平偏空。先定大尺度，再做组件。
- 同一家族组件共用描边/配色/状态小杯，但剪影必须各自不同（vb13 照搬签条剪影被否：「一模一样了」）。
- **同一件作品**（茶茶最欣赏的）：页面、组件、角色、装饰、图案做成一件作品；每个小角落都看得出经过设计，不是自动生成的圆角矩形。保留插画级构图、装饰层次、材料表达、整体完成度，同时界面要真能操作。
- 以后研究喜欢的设计，看五样：轮廓、层次、密度、材质、空间连接方式，慢慢沉淀成 PPST 自己的设计语言。

## UI 六阶段（2026-11-21 茶茶，以后都按这个做）
1. **主题与视觉隐喻**：用 IDEATION 六种创意方法（类比、移植、模仿、组合、逆向、系统）发散，选一套核心视觉语言。颜色材质只是素材，设计概念是「私人手帐工作台」「魔法档案柜」「纸艺机关盒」这种层级，会产生完全不同的构图。
2. **视觉语言板（Visual Language Board）**：统一主辅色、材质、外轮廓、装饰母题、字体、边框、阴影、图案；并设计装饰之间怎么连接（如蝴蝶结连丝带、丝带连卡片、卡片从书页边伸出），免得每个组件像不同素材包。
3. **整页构图**：先别做按钮细节。定视觉主角在哪、内容区多大、哪里密哪里留白、什么可破框、什么必须清楚。至少三种明显不同的构图（灰稿），不是挪几张卡。
4. **组件家族**：按钮、输入框、卡片、弹窗、导航、标签同一套美术体系；形状和装饰密度可不同，但共享材质、线条、颜色与连接结构。
5. **可交互样页（Vertical Slice）**：只挑一页（如设置页）做完整视觉+交互，放真实模型名、长文本、加载、错误、选中态，真机能用。没验收前不铺开别页。
6. **截图对照与艺术评审**：看整页视觉重量、空间层次、主题一致性、交互清晰度。太空先查是否缺结构；太乱先查焦点和装饰密度；不粗暴增删小图标。

## 今天页为什么好（2026-11-21，作其他页大尺度基准）
- 一个巨大主角（芭菲）占屏六成以上，出血到屏边，就是页面的骨架，不是放在卡里的插图。
- 信息长在主角身上：日期、计数写在插进芭菲的小旗、挂牌上，内容绕着主角排，不另起盒子。
- 大标题（Good Morning + 11.20）压在主角上方，和主角互相咬合。
- 前后层清楚：淋酱在最上、主角居中、文字垫在主角缝里，留白在主角四周而不是空盒子里。
- 对照其他页：渠道、健康、搜索、请柬偏平——主角小或缺席，内容是一条条横排，缺大尺度结构。
