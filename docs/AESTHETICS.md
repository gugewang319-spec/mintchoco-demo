# 审美笔记（茶茶给的参考 → 学到的方法）

只记方法，不搬元素。每次精修组件前先读一遍。

## 2026-11-20 票根/小票七张（CoC 票根、@ssugartype 聊天框、石原包美《漏网之鱼》票根、ILUwm Frosted Clarity 镭射票、风 Elysium 镭射票练习、月希星星票根模板、红烧兔头 Aurora 票根素材）
1. **一个压得住的大标题**：花体 / 衬线斜体 / 粗字标，占画面 1/3，可以压过图框边（字叠图是杂志手法）。小字全部当纹理。
2. **三色以内，高对比**：蓝白黑、红米黑、藏青米白。同一张票出 2–3 个换色版（浅底 / 色底 / 深底）表示不同状态。
3. **画面窗**：拱门、椭圆、波浪圆、长方形——票是相框，里面放主角图。
4. **细线装饰而不是粗描边**：双细线内框、虚点线、角花、绕星的椭圆轨道、点线上缀小星。外轮廓通常不描边，只靠底色和投影。
5. **票根区**：竖排小字、大号竖排编号、圆形环绕文字章、条码/二维码感的小块；打孔半圆 + 虚线分隔。
6. **边缘有工艺**：邮票齿边、打孔、剪角。
7. **渐变是色场往白里化开**（Elysium），不是 3D 光泽。
8. **拼贴密度**（Aurora）：格纹块、圆形徽章、色票圆点列、诗句微缩字，层层压角但中间留白。
9. **对齐与留白**：元素都卡在网格上，边距充足；乱中有序。
